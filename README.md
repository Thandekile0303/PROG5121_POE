# PROG5121 POE - QuickChat App

## Part 1: Registration and Login

A console-based Java application that registers users with validation rules.

### Features
- Username validation (must contain `_` and be ≤ 5 characters)
- Password complexity check (8+ chars, capital letter, digit, special character)
- Cell phone validation (+27 international code)
- User login with stored credentials

### How to Run
Run `PROG5121_POE.java` in NetBeans.

### Testing
Unit tests are in `LoginTest.java`. Run with Ctrl+F6 in NetBeans.
